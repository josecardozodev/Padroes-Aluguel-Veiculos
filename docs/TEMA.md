# Sistema para Aluguel de Veículos
O sistema de aluguel de veículos contemplará os 5 Padrões de Projeto trabalhados nesta matéria, fornecendo serviços de cadastro de veículos, aluguel de veículos, escolha de planos e clonagem de veículos e modelos.

A intenção é que o cliente consiga cadastrar um veículo e efetuar uma reserva dele dentro do sistema, utilizando dos padrões trabalhados e respeitando possíveis regras de negócio dentro deste escopo.
